# AICE Academy practice service

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/DEFRA/aice-academy-practice)

This is where you build "Report a hedgehog sighting" in the AICE Academy. It's Defra's CDP Node.js frontend template with the academy starter kit added, ready to open in your browser with nothing to install.

- **In your browser (recommended):** select **Open in GitHub Codespaces** above, then follow `START-HERE.md`.
- **On your laptop:** clone this repo, then run `nvm install`, `npm install`, `npm test` and `npm run dev`, and start Claude Code with `claude`.

The academy itself, with every mission, is the AICE Academy service. This repo is generated from `DEFRA/aice-academy` by `scripts/build-practice-repo.sh`: change the starter kit there, not here.
