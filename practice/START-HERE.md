# Start here

Welcome to your AICE Academy practice service. This codespace already has everything you need: Defra's CDP frontend template, the academy starter kit, Node.js, Claude Code and a database for Mission 8.

Keep the AICE Academy service open in another tab. It shows each step with more help. These are the same steps, in short.

## Step 3: Wait while it gets ready

The first time, setup takes a few minutes. Text scrolls past in the terminal at the bottom of the screen. That's normal, and you don't need to read it. Carry on when it says **Your practice service is ready**.

## Step 4: Start your service

Select inside the terminal, paste this and press **Enter**:

```bash
npm run dev
```

After about 20 seconds, a tab called **Your service** opens. If it doesn't, open the **Ports** tab at the bottom and select the globe icon next to port 3000.

Leave this terminal running.

## Step 5: Open Claude

Open a second terminal (select the **+** in the terminal panel), paste this and press **Enter**:

```bash
claude
```

Sign in with the account your facilitator gave you. If Claude asks whether you trust the files in this folder, choose **Yes**.

## Step 6: Say hello to your team

Type this and press **Enter**:

```
/academy
```

Claude checks your setup and introduces your AI team. When it asks permission to run something, read it and choose **Yes** if it makes sense.

## Good to know

- **Your work is saved.** A codespace stops after 30 minutes without activity, but nothing is lost. Reopen it from [github.com/codespaces](https://github.com/codespaces).
- **Don't delete your codespace** until you've finished Mission 10.
- **Stuck?** Every step and mission in the AICE Academy service has help for when things don't look right.
