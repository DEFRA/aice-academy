## What you'll do

You'll plan the journey: every page someone sees, from the start page to the confirmation. GOV.UK services ask **one question per page**, because it's easier for everyone, especially on phones and with assistive technology.

## Steps

### 1. Ask the designer to plan the journey

```
Ask the interaction designer to plan the journey and write a short description of each page.
```

Claude will ask permission to create a few files for the plan. Allow it.

### 2. Get two teammates to check it at the same time

```
Ask the content designer and the accessibility checker to review the page descriptions at the same time.
```

Teammates can work side by side, like colleagues reviewing a document together. Claude collects what they both say.

### 3. Look at the plan

```
Show me the journey as a numbered list of pages, with the question on each.
```

### 4. Make it simpler

For each question, ask yourself: what will the team do with this answer? If nothing, take it out. Tell Claude what to change, then say you approve the plan.
