## What's happening

Your codespace is installing the tools it needs. You don't need to do anything.

You'll see lots of text scrolling past at the bottom of the screen. **That's normal, and you don't need to read it.** It's the computer telling itself what it's doing.

## What your screen looks like

Your codespace looks like a code editor, a program developers use to write code. Don't worry: you won't need to write code yourself. Claude does that.

- **On the left:** a list of files.
- **In the middle:** a file called START-HERE.md, open for you.
- **At the bottom:** the **terminal**, a panel where you type instructions for the computer. This is where the scrolling text appears.

## While you wait

Meet [your AI team (opens in new tab)](/how-it-works#meet-your-team).

Come back when the bottom panel says **Your practice service is ready**.
