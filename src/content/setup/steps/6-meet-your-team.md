## What you're about to do

You'll ask Claude to start the academy. Claude checks everything is working and introduces your AI team.

## Do this

1. In the Claude terminal, type this and press **Enter**:

```
/academy
```

The slash at the start tells Claude this is a shortcut to a set of instructions, not an ordinary message.

2. Claude asks permission before running commands, such as running the tests. Read what it wants to do, then choose **Yes** if it makes sense. If you're not sure, [read when Claude asks permission](/claude-permissions).

3. Read Claude's reply. It tells you what it checked and what comes next.
