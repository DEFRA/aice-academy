## What GitHub is

GitHub is a website where people keep the code for websites and apps. Defra keeps the code for its services there.

You need a free account so GitHub can give you your own workspace: a ready-made computer that runs in your web browser. Everything you build lives there, so nothing gets installed on your laptop.

## Do this

1. Go to [GitHub's sign-up page (opens in new tab)](https://github.com/signup).
2. Enter your email address, make a password and choose a username. Your username is public, so use something professional, like your name.
3. GitHub sends a code to your email. Type it in.
4. If GitHub asks you questions about how you'll use it, you can skip them.

Already have an account? [Sign in to GitHub (opens in new tab)](https://github.com/login) instead.
