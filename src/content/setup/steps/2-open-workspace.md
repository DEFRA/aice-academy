## What you're about to do

You'll create your **codespace**: your own workspace that runs in a browser tab. It already has everything you need, including Defra's starting point for building services and your AI team.

It's a practice copy. You can't break anything real.

## Do this

1. Select the link below. It opens GitHub in a new tab, so you can keep this page open.
2. If GitHub asks you to sign in, sign in.
3. Select the green **Create codespace** button.

[Create your workspace (opens in new tab)](https://codespaces.new/DEFRA/aice-academy-practice)

When the new tab starts setting up, come back to this tab for the next step.
