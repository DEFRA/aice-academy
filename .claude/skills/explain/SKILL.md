# Explain it simply

Explain $ARGUMENTS (or, if blank, the most recent change) to someone who is clever but new to code.

- Start with one sentence: what it does for the user of the service.
- Then explain how, in no more than five short bullet points.
- Use an everyday comparison where it helps (for example "a route is like a signpost: it sends each web address to the right handler").
- Point to the exact file and line so they can look for themselves.
- End with one question they could try asking Claude next to go deeper.

No jargon without a plain-English explanation in brackets.
